Google Maps API 設定

本工具是本機 HTML，但地圖與商店資料仍會透過網路向 Google Maps Platform 查詢。

安全提醒：以 file:// 開啟本機 HTML 時，網站來源限制通常無法可靠驗證。請使用獨立測試金鑰、只允許 Maps JavaScript API 與 Places API（New），並設定每日配額及預算警示。
Google Cloud 必要設定
  1. 啟用 Maps JavaScript API。
  2. 啟用 Places API（New）。
  3. API restrictions 只勾選上面兩項。
  4. 本機 file:// 版本通常要把 Application restrictions 設為「None」才能運作，因此務必限制配額。
